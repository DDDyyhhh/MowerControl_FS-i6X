# 2026-09-30 PWM 台架重复启动修复镜像

这是一对仅供刀盘和电调物理断开时测 PA1 的台架镜像，由现场操作者刷写。双端均需更新；不作为正式割刀固件。源码、构建开关和刷写方法见上级 Ticket03 README。本目录固定保存本次构建结果，避免后续构建覆盖同名文件造成混用。

- 遥控器：`openi6x-exp3-pwm-restart.bin`，128732 B。
- 底盘：`control-chassis-exp3-pwm-restart.hex`，227714 B。

修复：Cancel 回执等待期间显示 `WAIT CANCEL`，不再显示不能执行的 OK；等待期间仍记录 CH4 边沿；旧 Cancel 不清除更新的 CH4 启动请求；底盘用当前 CH4 代数拒绝过期事件。串口增加 `deny` 拒绝原因。

复测步骤：

1. 双端刷写后等待 `E3 READY` 和串口 `bound=1`，完成正常遥控运行许可。
2. 在割刀页将 CH4 回中约 1500，保持至少一秒，再左打约 988。
3. `START BLADE? > OK` 出现后短按一次 OK，等待 `WAIT RESULT` 约 25–30 秒。
4. 出现 `TEST ACCEPTED` 时同时记录串口和 PA1。应为 `deny=0`、`reject=0`、`blade=2`（RUNNING）、`gate=0`，`confirm` 只增加一次；新通道帧前 `ccr2=0`，之后 CH7 低/中/高分别为约 3780/4200/4620，对应约 10 kHz、45/50/55%。万用表电压变化只能证明输出有响应，不能代替频率和占空比测量。
5. CH4 回中应立即停止 PA1；界面显示 `WAIT CANCEL`。等等待结束，再左打并按 OK；也应能完成新的独立确认。提前左打时保持等待，等待结束后才显示新启动提示，期间按的 OK 不会被排队执行。
6. 若再次 `TEST ACCEPTED` 却无输出，保留此时串口 `EXP3 ...` 完整行。`deny`：1 安全门，2 割刀未处于等待确认，3 无待确认请求，4 CH4 不在启动位置，5 上下文/目标不符，6 CH4 代数不符，7 确认序号耗尽。该码是最后一次事件判定，当前状态仍需看 `blade/gate/ccr2`。

主机回归、双端 ARM 构建和仓库完整验证已通过；这对镜像尚未获得现场重复启动与 PA1 示波器验收结果。
