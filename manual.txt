 F Y Fig.4-2. Connection
KY IPSK The USB connection ESC is the master board, and all others connected via CAN bus are
  L slave boards. Theoretically, 1 master board can be connected with a maximum of 253 slave CAN

                devices (except for master ESC ID, ESC ID=0 and ESC ID=255). While, it is recommended not

  F Y using more than 8 slave boards in practice since too many CAN devices affect the working
  K performance efficiency. Moreover, please remove the CAN terminal resistors except for the first

                and last ESCs' CANs. Set 1pcs Master ESC and 6pcs Slave ESCs as an example:

   Y PS Master(Start)==Slave1==Slave2==Slave3==Slave4==Slave5==Slave6(End)
   K I Remove the CAN terminal resistors of Slave1, Slave2, Slave3, Slave4 and Slave5, leaving only
   S L the CAN terminal resistors of Master (Start) and Slave6 (End).

P 4.2 CAN Devices Connection Error and Solution
I If multiple ESCs are connected via CAN but one cannot communicate and the Flipsky ESC Tool
L detects that the number of ESC is less than actually connected, 3 possible causes are as below:
F 1) The slave ESC boards' CAN terminal resistors haven't been removed.
K 2) Different ESCs with same IDs
S 3) One of ESC's CAN baud rate is inconsistent with others.

     Solution:

Y P (1) Ensure that all CAN resistance are properly configured.(view Section 4.1)
K I (2) After step (1), unplug the CAN-BUS wires. Check the ESC ID one by one by connecting
S L them with the ESC Tool separately via USB cable. If same IDs happen, revise them to make sure
P F the uniqueness of the ESC ID.

     (3) If it has been verified that all ESCs have different ESC IDs and the CAN end resistance has

I been configured correctly, but you are still unable to detect the other ESCs on the CAN bus, you
L can continue to check whether the CAN baud rate setting is consistent with the others. Only you
F Y can communicate normally when you make sure that the CAN baud rate setup of all ESCs are the
K same.

     (4) If still not succeed after the above trials, please restore all the ESCs default setup and try to

S reconnect.
