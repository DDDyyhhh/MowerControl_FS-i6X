# CH6 集草袋刷写与复测说明

2026-10-09。此文提供用户执行步骤；本次没有刷写或硬件验证。

## 刷写

| 设备 | 文件 | 写入地址 |
|---|---|---|
| STM32F407 底盘 | `control-chassis-grass-bag-ch6.elf` | ELF 自带 |

刷写前：断开割刀动力电源，保持控制板可供电；架空车轮，清空草袋并清理开合机构附近，确保机构可随时断电。CH5 置停机/上锁档，CH6 置约 2000（关闭档），CH4 回中；开合电机动力先断开。只有需要刷写的板连接适配器。

底盘接 ST-Link，在本目录执行：

```bash
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg \
  -c 'program control-chassis-grass-bag-ch6.elf verify reset exit'
```

必须看到 `Verified OK`。

不擦除/改写校准和用户设置区域，不执行全片擦除命令。不要使用 Debug 或历史包文件代替本次 ELF。

BIN／HEX 写法、备份、读回和排障见[通用刷写指南](../../docs/flashing.md)。

## 先检查输入，再接草袋动力

- 遥控器查看当前模型的 SB→CH6 混控、反向设置和输出监视：两个稳定档应分别约 1000/2000。
- 调试器观察 `g_command.grass_bag_raw`、`grass_bag_configured` 和 `grass_bag_target`；OPEN 枚举=1，CLOSED=2，UNKNOWN=0。仅观察即可，不写变量强制解锁。
- 主板 PD10 低电平表示草袋连接。先保持上锁，核对草袋开合 PWM：TIM2 CH4 为打开侧，CH3 为关闭侧，应均为 0。
- 接草袋电机动力前，先确认割刀仍断电、车轮仍架空、机构附近无人。
- CH5 置允许，按现有 CH8 高→低→高解锁流程操作，摇杆回中保持，确认解锁。CH6 当前档只建立基线，机构应保持静止；不要用 CH6 代替刀盘 OK。

## 硬件复测表

所有项目默认“待测”。记录操作员、时间、两档 CH6 原始值、两路 PWM、实际方向及耗时。

| 场景 | 操作与预期 | 实测结果 |
| --- | --- | --- |
| 上电基线 | CH6 在 1000 或 2000 上电并解锁，机构不自动动作 | 待测 |
| 打开 | 基线在关闭档后拨至 1000，三帧稳定后向打开方向运行 | 待测 |
| 保持打开档 | 同档保持，单次计时约 20s 后 PWM 清零，不反复启动 | 待测 |
| 关闭 | 从打开档拨至 2000，向关闭方向运行，约 20s 后 PWM 清零 | 待测 |
| 中间值/抖动 | 约1500及少于三帧的抖动，不产生新目标 | 待测 |
| 动作中换向 | 1000→2000 或反向，先清零，再启动新方向；重新计时 | 待测 |
| 上锁 | 开合途中 CH5 停机，PWM 清零，不在旧20s截止时误报完成 | 待测 |
| 急停 | 开合途中触发急停，PWM 清零；记录实际停止延迟 | 待测 |
| 碰撞 | 开合途中触发碰撞，锁存停车、PWM 清零；物理回弹不恢复 | 待测 |
| 倾斜保护 | 用已有可控姿态测试方式验证保护触发后停止；避免带动力倾翻设备 | 待测 |
| 断链 | 关遥控器/断开 i-BUS；100ms超时阈值后下一10ms控制周期停止，记录实际时延 | 待测 |
| 断链恢复 | 重新在线及授权后 CH6 保持原档不动作；新拨动才动作 | 待测 |
| 草袋断开 | 开合途中断开连接检测，PWM 清零；重接不自动恢复 | 待测 |
| 模式切换 | 进入API待机时中止手动动作，API期间CH6不抢控制权 | 待测 |
| API目标 | 正常进入API运行并50ms重复发送Byte6，目标幂等；物理故障/断袋/API心跳超时停止 | 待测 |
| 返回手动 | 完成重新授权后建立CH6基线，新拨动才动作 | 待测 |
| 刀盘授权回归 | CH6拨动不能确认刀盘；CH4新启动请求仍需显式OK（先断动力检查） | 待测 |
| 行驶回归 | CH2端点方向、CH10调速以及既有停车/解锁保护正常 | 待测 |

## 证据和限制

- 无物理限位，完成状态只按运行时间估算，不能证明机械到位。中止保持上次完成状态，机构可能停在中间位置。
- 中止后重新请求任一方向会从当前位置重新运行最多 20 秒；换向、堵转电流、机械限位承受时间都需现场确认。未完成实测前不标记为硬件验收通过。
- 记录发生故障时刻与PWM清零时刻，区分软件指令停止和机械实际停转。不要把100ms超时阈值直接写成实测停车延迟。
- API 心跳阈值沿用500ms；CH6 的遥控链路阈值为100ms。重新授权由现有安全状态机完成。
- 如需回退，使用 `../20261008-mower-v1/control-chassis-mower-v1.elf`。旧版本不提供本次CH6草袋控制。
