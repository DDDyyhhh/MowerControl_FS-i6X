# v2 回退版：刷写与复测说明

本包以 `20261026-single-unlock-estop-v2` 为源码基线，撤回 v34 快速解锁改动，将电池反馈缺失、超时和数值无效改为仅诊断。有效 SOC＜20% 或整包电压＜48.00V 的原有低电禁刀保留。尚未刷写硬件，以下实机项目均为待测。

## 刷写

| 设备 | 文件 | 写入地址 |
|---|---|---|
| STM32F407 底盘 | `control-chassis-bms-diag.elf` | ELF 自带 |
| FS-i6X 遥控器 | `fs-i6x-bms-diag.bin` | `0x08000000` |

刷写前：保留当前固件、遥控器模型及校准参数，沿用现有动力隔离台架流程。先完成隔离条件下的逻辑复测，再按现场流程测试执行器响应。

底盘接 ST-Link，在本目录执行：

```bash
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg \
  -c 'program control-chassis-bms-diag.elf verify reset exit'
```

必须看到 `Verified OK`。

遥控器先进入 USB DFU，用 `dfu-util -l` 确认只连了目标遥控器、Internal Flash 是 alt 0（不是就换成实际值），在本目录执行：

```bash
dfu-util -a 0 -s 0x08000000:leave -D fs-i6x-bms-diag.bin
```

必须看到 `File downloaded successfully`。

两端均使用本包并重新上电。逻辑协议为 `0x33`，快速状态为地址10/E9 profile2；不要搭配 v34 固件。文件大小、软件验证及存储占用见 `release.json`。

BIN／HEX 写法、备份、读回和排障见[通用刷写指南](../../docs/flashing.md)。

## 正常操作与预期显示

沿用 v2 授权逻辑：链路稳定后，CH1/CH2 连续回中至少200ms，CH4回中约1500，再左拨约1000并按新的OK。解锁成功后仍需新控制帧才允许行走；割刀需要再次完成独立的CH4回中、左拨与OK。本包未引入 v34 的开机快速操作代次方案。

无 BMS 或反馈异常时，仍按上述方式解锁、行走和独立启刀。首页电池数值显示 `--`，单独的反馈异常不会显示“电池异常”或通用“报错”；调试页“电池反馈异常”项标记 `!`，原因诊断有新鲜回传时显示“数据失效”，否则显示未知。正常开机显示“锁定”，等待合法解锁。

有效低电仍显示“请充电”、停止并禁止割刀，行走不因低电降速。低电已确认后，即使 BMS 断开或电压回升，禁刀仍保持到重新上电；解锁不能清除低电禁刀。数据恢复不会自动解锁、行走或启刀。

## 电池与操控复测

通过现有 BMS 模拟器或台架注入测试数据；保持通讯帧其他字段有效，避免将电池反复放电到硬切断。实际执行器状态和屏幕状态分别记录。

| 编号 | 操作/条件 | 预期 | 结果/证据 |
| --- | --- | --- | --- |
| B01 | 不连接BMS，分别底盘先开、遥控器先开、同时开；每种至少20轮 | 稳定链路后合法解锁成功；可行走；独立确认后可启刀；调试页显示反馈异常 | 待测 |
| B02 | 正常解锁后中断BMS反馈超过3秒，保持遥控链路正常 | 电池数值变未知；不因BMS故障上锁、撤销授权、停车或停刀；遥控停止指令仍有效 | 待测 |
| B03 | 注入无效SOC、零电压或无效单体值 | 仅反馈异常；不把无效低值判为真实低电，不拦截合法操作 | 待测 |
| B04 | B01/B02/B03后恢复有效正常数据 | 数值恢复；无数据恢复等待或额外解锁门槛；保持原有锁定/授权状态 | 待测 |
| B05 | 系统锁定时恢复BMS，或曾按过不满足安全条件的OK后恢复 | 不自动解锁，不执行旧OK，不自动启刀 | 待测 |
| B06 | 有效SOC=20%、总压=48.00V及略高于阈值 | 不触发低电禁刀 | 待测 |
| B07 | 有效SOC=19%或总压=47.99V，新样本连续覆盖2秒 | 停刀并锁存禁刀；行走仍可用；启动操作提示禁止开启割刀 | 待测 |
| B08 | 开机首个有效样本即低电 | 2秒确认前也无短暂启刀窗口；数据有效性保持真实 | 待测 |
| B09 | 已正常运行时短暂低值不足2秒，或样本冻结/间隔超过1500ms | 不以重复旧样本累加低电时长；按原去抖规则判断 | 待测 |
| B10 | B07后丢失BMS反馈，再恢复正常电量、普通解锁或切换模式 | 低电禁刀持续，仍提示充电；行走许可不因BMS异常撤销 | 待测 |
| B11 | 低电锁存后重新上电 | 清除上一轮低电锁存并按新真实数据判断；不自动授权或启刀 | 待测 |

1999/2000ms低电确认、2999/3000ms反馈时效以及199/200ms摇杆回中的精确边界由主机确定性回归验证；人工操作不能替代毫秒边界结论。

## 安全与 v2 恢复复测

| 场景 | 预期 | 结果/证据 |
| --- | --- | --- |
| 急停、碰撞触发，含BMS反馈异常时 | 原有停车停刀与原因锁存有效 | 待测 |
| 释放急停/碰撞后合法解锁，各至少20轮 | 一次完整解锁恢复遥控；割刀继续关闭，需独立确认 | 待测 |
| 安全输入未释放、摇杆未回中时按OK | 拒绝；解除条件后不会执行旧OK | 待测 |
| 碰撞与急停先后或同时触发 | 两类原因保持，碰撞显示优先；合法解锁清除已释放原因 | 待测 |
| 遥控断链、单端重启或冻结运行状态回传 | 原有超时停车和新会话授权要求有效；BMS故障不被当作遥控断链 | 待测 |
| 重复OK、旧确认、取消交错 | 无重复授权或意外启刀；停止操作有效 | 待测 |
| 行走、割刀三档、升降和草袋操作 | 功能与v2一致；低电仅限制割刀 | 待测 |
