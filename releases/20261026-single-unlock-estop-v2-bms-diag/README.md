# v2 回退与电池反馈仅诊断版

以 `20261026-single-unlock-estop-v2` 为基线，恢复原0x33/E9 v2授权协议，撤回v34快速操作代次方案。电池反馈缺失、超时或数值无效仅在调试页显示“电池反馈异常”，电池数值显示 `--`；不拦截解锁、行走和独立确认后的割刀操作，不在首页触发电池异常或通用报错。

有效SOC＜20%或总压＜48.00V的原有低电禁刀、2秒确认和有效低电启动检查保留。已确认的低电在反馈丢失或电压回升后仍禁刀，行走不因低电降速。反馈恢复不自动解锁或启刀。急停、碰撞、倾斜、断链和控制权规则保持。

## 配套刷写

| 设备 | BIN | 起始地址 |
| --- | --- | --- |
| STM32F407底盘 | `control-chassis-bms-diag.bin` | `0x08000000` |
| FS-i6X遥控器 | `fs-i6x-bms-diag.bin` | `0x08000000` |

同时提供ELF、HEX、MAP。两端配套刷写并重新上电，详细命令和待测矩阵见[刷写与复测说明](刷写与复测说明.md)。向量表及ELF/HEX导出BIN逐字节一致已检查。

## 软件验证

全套主机回归、底盘Debug/Release、FS-i6X正式构建及全新目录源码复建通过；15组修改前后同参数编译警告集合一致。测试涵盖无反馈/超时/无效/恢复、独立启刀、有效低电与阈值边界、低电后掉反馈、急停/碰撞/断链及旧OK拒绝。36张原界面中35张逐像素一致，仅电池反馈异常首页按需求改变；新增调试行预览。详情见 `validation/`，界面效果见 `validation/battery-policy-preview.png`。

遥控器Flash 130872/131072字节，剩余200字节；静态RAM 15836/16384字节，剩余548字节。SVN预检通过，保留既有EIDE产物、此前字库及Keil工程变更三类提示。

## 源码与复建

`buildable-source.tar.gz`提供完整构建输入，`validation/source-files.json`记录逐文件哈希，`changes.patch`记录相对原始v2的13个文件差异。`bash rebuild.sh`解压到新的 `/tmp` 目录并执行 `tools/build_blade_ok.sh`，需要本机Arm GNU15.3.1、CMake、Ninja和宿主编译器。版本时间标记可能变化，不保证复建BIN哈希相同。
