# 遥控器刷写与实机复测

仅更新 FS-i6X；保留现有底盘固件及遥控器模型、混控、通道反向/端点和校准数据，不清除 EEPROM。
本包是软件验证通过的候选版，以下实机项目尚未执行。

## 刷写

| 设备 | 文件 | 写入地址 |
|---|---|---|
| FS-i6X 遥控器 | `fs-i6x-simple-ui.bin` | `0x08000000` |

刷写前：先保存遥控器当前镜像和模型。隔离割刀动力、固定车轮，保持底盘急停。不能将该文件写入底盘。

遥控器先进入 USB DFU，用 `dfu-util -l` 确认只连了目标遥控器、Internal Flash 是 alt 0（不是就换成实际值），在本目录执行：

```bash
dfu-util -a 0 -s 0x08000000:leave -D fs-i6x-simple-ui.bin
```

必须看到 `File downloaded successfully`。

正常开机完成原安全检查，验证原模型和有效校准仍在。异常校准仍应按原要求完整重做。

BIN／HEX 写法、备份、读回和排障见[通用刷写指南](../../docs/flashing.md)。

## 操作说明

- 主界面：日常只需观察五行状态，速度和机构操作继续使用原旋钮/开关。
- 维护入口：长按右键，上下选择，短按 OK；长按后的松键不会执行选择。
- 调试：上下逐行滚动，支持按住重复滚动；EXIT 返回维护，再按 EXIT 返回主界面。
- 设置和校准：维护入口 → 系统设置，沿用原英文系统菜单；模型配置由模型设置进入。
- 割刀：沿用原 CH4 操作和短按 OK 确认；弹窗中文化，取消等待及无回执闭锁保持。EXIT 不作为停刀键。
- “高度设”“袋指令”是本地设定，不能用来判断升降完成或草袋到位。

## 验收表

全程先以动力隔离状态检查遥控输入与控制器输出；机械动作验收沿用原项目测试方式。

| 项目 | 通过标准 | 实机记录 |
|---|---|---|
| 开机 | 必要校准/安全检查后只有中文主界面，字符完整且无闪烁、卡顿或异常重启 | 待测 |
| 普通翻页 | 主界面短按上下左右不出现旧 DATA、FAULT、通道、计时器页 | 待测 |
| 维护导航 | 长按右键进入；松键不误选；调试可滚动全部内容；EXIT 逐级返回 | 待测 |
| 维护重启 | 在维护/调试页关机，再开机仍回主界面 | 待测 |
| 原设置 | 系统/模型设置及校准可达；原模型、混控、反向、端点和有效校准保留 | 待测 |
| 行走设定 | CH10 两端显示 0.40、1.80 m/s，中间连续变化；原行走行为保持 | 待测 |
| 割刀显示 | 有新鲜回显时显示对应档位/使能；断链后显示未知，不把输出关解释为机械停转 | 待测 |
| 高度设定 | CH9 五档稳定显示，边界无明显抖动，标签明确是设定 | 待测 |
| 草袋指令 | CH6 两端分别显示开/关；中间显示未知，机械基线建立或中止不被误报完成 | 待测 |
| 连接与电量 | 断链后显示未连接、未知整车电量和信号；恢复后只显示有效反馈 | 待测 |
| 底盘反馈失效 | BMS/轮速/割刀反馈失效时对应值显示 `--`，不显示假零值 | 待测 |
| 故障 | 保持动力隔离，按既有方式验证故障提示；调试能看到对应故障位，多个故障均可查 | 待测 |
| 启动确认 | 原 CH4 新边沿提示、短按 OK 确认；长按 OK 松键不确认，维护选择 OK 不确认 | 待测 |
| 取消与切页 | CH4 回中后后台取消继续；弹窗消失不代表取消完成，忙期间 OK 不缓存 | 待测 |
| 再启动 | 立即回中再左打提示正确，待取消成功后必须新的短按 OK；迟到旧回执不授权 | 待测 |
| 安全恢复 | 原断链/急停/碰撞及重新授权流程有效，旧开关位置或旧 OK 不恢复运行 | 待测 |

## 回退

优先刷回设备刷写前保存的镜像。也可沿用上述 DFU 步骤写入 `rollback/fs-i6x-mower-v1.bin`，恢复原已验收的 MOWER/DATA/FAULT 界面。该文件与原 2026-10-08 发布包完全一致；底盘仍不需要重刷。
