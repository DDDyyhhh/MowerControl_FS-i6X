# 刀盘升降 15 kHz／60%：双端刷写与复测

本包对应新项目 r109、协议 **0x36**，包含 STM32F407 底盘与 FS-i6X 遥控器两端完整镜像。升降 15 kHz／60%，草袋仍为 10 kHz／60%；割刀保持 FTESC CAN。现有实体急停启用配置 `VEHICLE_ESTOP_ENABLED=1` 保留，实际输入与停车效果仍需现场验收。

## 刷写

| 设备 | 文件 | 写入地址 |
|---|---|---|
| STM32F407 底盘 | `control-chassis-lifter-15khz60pct.elf` | ELF 自带 |
| FS-i6X 遥控器 | `fs-i6x-lifter15khz-paired.bin` | `0x08000000` |

刷写前：固定设备，隔离行走、割刀和推杆动力，先只给逻辑板及接收机供电；保存设备当前固件、遥控器模型、校准、绑定、通道和失控保护配置。保留外部 EEPROM、模型和 Option Bytes，只擦写镜像需要的程序区域。两端镜像不能交叉使用。

底盘接 ST-Link，在本目录执行：

```bash
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg \
  -c 'adapter speed 100' -c 'reset_config none' \
  -c 'program control-chassis-lifter-15khz60pct.elf verify reset exit'
```

必须看到 `Verified OK`。

遥控器先进入 USB DFU，用 `dfu-util -l` 确认只连了目标遥控器、Internal Flash 是 alt 0（不是就换成实际值），在本目录执行：

```bash
dfu-util -a 0 -s 0x08000000 -D fs-i6x-lifter15khz-paired.bin
```

必须看到 `File downloaded successfully`。完成后拔 USB，正常开机。

BIN／HEX 写法、备份、读回和排障见[通用刷写指南](../../docs/flashing.md)。

## 刷后复测（全部待现场执行）

先隔离电机动力，使用原有 CH4 回中→左拨→OK 解锁；割刀启动仍需新的独立操作与 OK。示波器先接逻辑板 GND，测量活动 PWM 通道；停止时没有周期波形。

| 场景 | 预期与记录内容 | 结果 |
|---|---|---|
| 开机／锁定／停止 | PB0、PB1 均为低电平，无旧动作恢复 | 待测 |
| 升降向上 | 沿用 r109 方向：PB1/TIM3_CH4 活动、PB0 低；约 15 kHz、66.67 μs、60%，高电平约 40 μs | 待测 |
| 升降向下 | PB0/TIM3_CH3 活动、PB1 低；约 15 kHz、60% | 待测 |
| 换向与撤权 | 原有先停止、CH5 关闭、急停、碰撞与通信故障均撤销输出；记录逻辑和机构停止时延 | 待测 |
| 草袋开／关 | TIM2 活动通道约 10 kHz、100 μs、60%，高电平约 60 μs；停止为 0% | 待测 |
| 两端通信 | 0x36 绑定、遥测、状态和独立 OK 正常；模型、校准及通道设置保留 | 待测 |
| i-BUS 无有效帧 | 默认 300 ms 撤权锁定；通信恢复不自动解锁，发射机关闭后持续有效 failsafe 帧须另行验证 | 待测 |
| 机构短程／档位 | 恢复受控推杆动力，验证方向、各档高度、运行时间、电流和温升；原时间表及估算高度需重新实测 | 待测 |

归位 10 秒、草袋运行 20 秒、上升补偿和原行程表不变。记录时间、人员、板卡和供电、实测频率／占空比、停止时延、实际高度与结论；软件验证不代替波形、机械标定和整车验收。

## 双端回退

优先使用刷写前从设备保存的镜像。`rollback/` 中底盘是本轮修改前、未改源码 r109 的本机重建镜像（升降及草袋均 10 kHz／60%），遥控器来自新项目原有 11 月 5 日 0x36 发布包。它们不是设备备份，也不保证是设备原来的版本。

底盘按上文相同接线与参数执行：

```sh
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg \
  -c 'adapter speed 100' -c 'reset_config none' \
  -c 'program rollback/control-chassis-r109-10khz60pct.elf verify reset exit'
```

需要一起恢复遥控器时，重新确认 DFU 目标和 Internal Flash alt 后执行：

```sh
dfu-util -a 0 -s 0x08000000 -D rollback/fs-i6x-r109-paired.bin
```

回退后重新验证开机锁定、解锁、遥测及推杆动作。
