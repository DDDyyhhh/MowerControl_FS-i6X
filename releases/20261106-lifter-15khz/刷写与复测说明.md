# 刀盘升降推杆 15 kHz：刷写与复测说明

本包用于 **STM32F407 底盘控制板**，仅刀盘升降推杆改为 15 kHz；草袋和割刀仍为 10 kHz。现有 0x33 协议 FS-i6X 遥控器继续使用。本包软件验证通过，以下刷写和硬件验收均待现场执行。

**沿用的 `VEHICLE_ESTOP_ENABLED=0` 会旁路 PD1 实体急停。刷写和复测前先物理隔离车轮、割刀及执行机构动力，不能依赖该急停输入。测量 PWM 时可先断开推杆电机动力，仅给逻辑板供电；恢复推杆动力前按现场条件落实可独立断电的控制措施。**

## 1. 准备、备份与包校验

1. 核对目标板与 STM32F407 芯片标识。用现有调试工具读取、保存设备当前固件和需要保留的参数，记录实际芯片容量、当前版本与备份 SHA256。
2. 保留现有遥控器模型、通道配置和配套 0x33 遥控器固件。首次使用 CH8／独立底盘 OK 版本时，先按 11 月 5 日发布说明完成配套遥控器更新与验收。
3. 关闭运行开关、摇杆与割刀指令回中，隔离动力。连接 ST-Link：SWDIO→PA13、SWCLK→PA14、GND→GND；按工具与板卡要求连接目标电压参考。可选连接 NRST。确认目标逻辑供电及共地正常。
4. 在本包目录执行校验，列出的文件必须全部为 `OK`。若使用 ZIP，先在交付目录检查 `ZIP-SHA256SUMS`，解压后再检查包内文件。

```sh
cd "/Users/dyh/Documents/Codex/MowerControl/releases/20261106-lifter-15khz"
shasum -a 256 -c SHA256SUMS
```

若包已复制到其他电脑或目录，将 `cd` 路径改为解压后的目录。没有安装 OpenOCD 时，使用 STM32CubeProgrammer 或原有 SWD 工具写入本包 HEX；写入 BIN 时必须指定 `0x08000000`，并启用写后校验。

## 2. 用 ST-Link / OpenOCD 刷写

以下命令会实际写入、校验并复位目标。连接多个调试器时先仅保留目标调试器，确认输出识别到预期 STM32F407 后操作。

推荐使用 ELF：

```sh
set -o pipefail
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg \
  -c 'program control-chassis-lifter-15khz.elf verify reset exit' \
  2>&1 | tee flash-lifter-15khz.log
```

若工具使用 HEX，可改为以下命令；二者任选其一：

```sh
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg \
  -c 'program control-chassis-lifter-15khz.hex verify reset exit'
```

仅使用 BIN 的工具需要以下地址：

```sh
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg \
  -c 'program control-chassis-lifter-15khz.bin 0x08000000 verify reset exit'
```

ELF／HEX 自带地址。按镜像范围擦写，避免全片擦除，以保留范围外已有设置。只有工具正常退出且写后校验成功，才能记录“刷写通过”；连接或校验失败时保留日志，检查供电、接线和目标识别后重试。

## 3. 逻辑输出与机构验收

先保持执行机构动力断开，正常开机并按现有 CH8／独立底盘 OK 流程取得升降运行权限。示波器探头接逻辑板 GND，以原有高度档位控制产生升降指令。**停止时两路均为低电平，没有周期波形；频率必须在活动通道上测量。**

| 场景 | 预期／需记录的数据 | 结果 |
|---|---|---|
| 开机／锁定 | PB0、PB1 均为低电平，无意外动作 | 待测 |
| 向上指令 | PB0 / TIM3_CH3 活动，PB1 低；约 15 kHz、66.67 μs、20%，高电平约 13.33 μs；记录实测频率、占空比与电平 | 待测 |
| 向下指令 | PB1 / TIM3_CH4 活动，PB0 低；约 15 kHz、66.67 μs、20%；记录实测值 | 待测 |
| 停止／目标到达 | PB0、PB1 均回到低电平；记录停止响应 | 待测 |
| 关闭运行权限 | 使用现有运行关闭操作，升降输出清零；重新授权后旧目标不自动恢复 | 待测 |
| 切换 CH8 模式 | 现有模式切换会停止升降，旧控制源目标不恢复；记录停止时延 | 待测 |
| 草袋输出 | 原有动作时 TIM2_CH3/PA2 或 CH4/PA3 为约 10 kHz，非活动通道为低 | 待测 |
| 割刀输出 | 原有合法确认流程下 TIM2_CH2/PA1 为约 10 kHz，停止为低 | 待测 |

确认逻辑输出后，在可控条件下恢复推杆动力：

1. 验证上升、下降方向和停止，再逐档检查 1～5 档目标及原有归位操作。
2. 本次仍使用原有占空比、定时行程表与估算位置。记录动作时间、实际高度、异常声音及是否存在卡滞；改变 PWM 频率后的真实速度和到位精度需要重新实测。
3. 在动作中验证权限撤销和模式切换确实停止机构，重新授权不会恢复旧目标。草袋与割刀先完成隔离动力下的信号复核，再按原有流程复测。

验收记录至少包含：时间、操作人、板卡／芯片型号、固件 SHA256、遥控器版本、供电、各方向频率和占空比、停止时延、各档实际高度与结论。波形截图可随测量记录保存；本包没有实测波形，也不宣告整车硬件安全验收通过。

## 4. 回退到 11 月 5 日底盘版本

优先恢复刷写前从本机保存的镜像。`rollback/` 附带的是既有发布包中的候选镜像，**不是设备备份，也不保证是设备刷写前的版本**；其来源为 `releases/20261105-ch8-mode-ok/`，保持 0x33 协议，升降 PWM 为 10 kHz。

在本包目录重新校验并恢复候选 HEX：

```sh
shasum -a 256 -c SHA256SUMS
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg \
  -c 'program rollback/control-chassis-ch8-ok.hex verify reset exit'
```

若使用候选 BIN，地址同为 `0x08000000`：

```sh
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg \
  -c 'program rollback/control-chassis-ch8-ok.bin 0x08000000 verify reset exit'
```

回退后重新核对开机锁定、独立 OK、升降输出与实际档位；保留刷写日志和回退记录。
