# CAN 自动恢复与快速握手：双端刷写与复测

本包基于 SVN r109 加未提交的工作副本改动，协议版本仍为 **0x36**，包含 STM32F407 底盘和 FS-i6X 遥控器两端镜像。**两端必须配套刷写**，只刷一端时开机握手提速不完整。

## 刷写

| 设备 | 文件 | 写入地址 |
|---|---|---|
| STM32F407 底盘 | `control-chassis-can-recovery-10khz50pct.elf` | ELF 自带 |
| FS-i6X 遥控器 | `fs-i6x-fast-handshake-paired.bin` | `0x08000000` |

刷写前：固定设备，隔离行走、割刀和推杆动力，先只给逻辑板及接收机供电。**拆下割刀刀片或确保周围无人。** ST-Link 接整车时，电脑最好用电池供电、不接充电器。不要选择 Option Bytes，也不要初始化外部 EEPROM。两端镜像不能交叉使用。

底盘接 ST-Link，在本目录执行：

```bash
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg \
  -c 'adapter speed 100' -c 'reset_config none' \
  -c 'program control-chassis-can-recovery-10khz50pct.elf verify reset exit'
```

必须看到 `Verified OK`。

遥控器先进入 USB DFU，用 `dfu-util -l` 确认只连了目标遥控器、Internal Flash 是 alt 0（不是就换成实际值），在本目录执行：

```bash
dfu-util -a 0 -s 0x08000000 -D fs-i6x-fast-handshake-paired.bin
```

必须看到 `File downloaded successfully`。完成后拔 USB，正常开机。

BIN／HEX 写法、备份、读回和排障见[通用刷写指南](../../docs/flashing.md)。

## 刷后复测

解锁方式不变：CH4 回中 → 左拨 → OK。割刀启动需要新的独立操作和 OK。首次启动割刀请用低挡短暂运行。

| 场景 | 预期 | 状态 |
|---|---|---|
| 遥控器先开，再开割草机 | 底盘 IMU 校准（约 2 秒）结束后可解锁，明显快于旧版 | 测试版已验证速度可接受 |
| 割草机先开，再开遥控器 | 同上 | 待测 |
| 运行中重启底盘 | 自动重新绑定，需重新解锁 | 待测 |
| 割刀转向 | 三个挡位方向正确，能升速，停刀正常 | 测试版已验证方向 |
| 推杆运行触发锁定后重新解锁 | 行走和割刀恢复控制，无突然动作 | 测试版已验证恢复 |
| 没接草袋时拨 CH6 | 草袋不动作，首页显示草袋未连接 | 待测 |
| 接上草袋开／合 | CH6 拨动后动作，约 20 秒结束 | 待测 |
| 推杆频率和占空比 | 升降 PB0／PB1、草袋 TIM2 CH3／CH4 均约 10 kHz、50%，停止为 0 | 待测（未用示波器实测） |
| 推杆启动 | 约 0.4 秒由慢变快 | 待测 |
| 高度显示 | **与实际存在偏差，需按 50% 占空比重新标定** | 已知问题 |
| 电池诊断 | 解锁后显示正常 | 待测 |

“测试版”指同样改动加上草袋连接绕过的台架固件；本包的底盘镜像本身只完成了刷写校验，建议按上表回归。

## 已知限制

- **推杆干扰未根治。** 同类工况下，台架固件在约 116 秒内记录到 50 次 CAN bus-off，i-BUS 也会中断并触发锁定。软件只保证能恢复，运行中仍可能短暂失控后安全停车，需要做硬件整改。
- **升降方向负载差异未查清。** 上升不锁定，下降和到顶空转时会锁定，原因待查。
- **负 ERPM 换向依赖电调行为。** 协议文档未明确说明，但实机方向已验证。

诊断时可用 ST-Link 在线读取，不需要复位。`g_can_bus_off_events` 的地址由 `nm` 从本包底盘 ELF 取得，整改后该计数应明显下降：

```sh
arm-none-eabi-nm control-chassis-can-recovery-10khz50pct.elf | grep g_can_bus_off_events
```

## 双端回退

优先使用刷写前从设备保存的镜像。`rollback/` 中是上一个发布包 `20261106-lifter-15khz` 的镜像（升降 15 kHz／60%，草袋 10 kHz／60%），不是设备备份。

**回退后割刀转向会变回反向**，CAN 自动恢复和握手提速也会失效。启动割刀前必须确认方向。

```sh
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg \
  -c 'adapter speed 100' -c 'reset_config none' \
  -c 'program rollback/control-chassis-lifter-15khz60pct.elf verify reset exit'
```

重新确认 DFU 目标和 alt 后，再回退遥控器：

```sh
dfu-util -a 0 -s 0x08000000 -D rollback/fs-i6x-lifter15khz-paired.bin
```

回退后重新验证开机锁定、解锁、遥测及推杆动作，并保留日志。
