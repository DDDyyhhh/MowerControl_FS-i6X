## 手工刷写

保持四轮稳定架空，割刀、升降、草袋动力隔离；CH5停止锁定，现场可独立断电。停止RK3588上的所有行走控制程序，不让刷写复位后恢复旧任务。先在本目录运行：

```bash
sha256sum -c SHA256SUMS
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg \
  -c 'program control_chassis.elf verify reset exit'
```

只在 `program ... verify reset exit` 成功后记录已刷写。连接失败时不要认为已烧录。保留旧发布 `20261010-api-ownership-fix` 作为回退材料，不覆盖其文件。

板端重启如can0为DOWN，重新启用500kbps，但先只接收0x507/0x50A，确认API=0、轮速近零且没有0x005控制发布者。任何运动都需新一轮人工解锁与现场准备确认，不发0xAA清锁。
