# FS-i6X 超声波避障设置 v38

适用正式 FlySky `MOWER_BLADE_OK` 双端固件，`EXP3_WIRE_VERSION=0x38`。在[v37 CH8/授权契约](ch8-control-source-v37.md)上增加本契约；其它控制源、授权、确认事务及超时规则沿用。决策见[ADR 0007](../adr/0007-ultrasonic-setting.md)。v35/v36/v37不能与v38建立授权会话，两端须配套升级。

## 上行与应用

正式STICKS包CH13（零基索引12，RF字节33/34，小端）传送设置；CH1～12及CH14原有含义不变，FAILSAFE包保持原行为。遥控器直接覆盖本设置，不改模型混控或EEPROM。

| CH13原始脉宽 | 设置 |
| --- | --- |
| 900..1120µs，发送1000 | 开启超声波避障 |
| 1880..2100µs，发送2000 | 关闭超声波避障 |
| 其它有效通道值 | 恢复开启并清除开启基线 |

Motion仅消费已绑定会话、连接新鲜且稳定的命令快照；同一帧不重复应用。底盘启动、未绑定或会话身份变化时恢复开启，清除开启基线；新会话必须先收到开启，随后才能接受关闭。遥控器启动、首页处理观察到未绑定/会话身份变化时将CH13恢复开启；底盘在此之前也不会接受旧关闭值。短暂失联时保留实际配置，但现有安全门禁止动力输出；链路恢复不授予动力权限。

`cfg_ultrasonic_en`继续由Motion上下文独占写入。开启沿用已有四探头距离读取及50/100/150cm阶梯限速；关闭沿用距离替换为250cm及跳过限速的行为。串口传感器采集持续运行。配置适用于原有遥控行走策略，API行走不新增超声波限制，不改变物理急停、碰撞、CH5或底盘锁。

## 下行与界面

SENS地址8、类型E0、16bit状态字的bit14：1表示底盘实际开启，0表示实际关闭。报文长度与其它位不变，该位不参与故障告警；E9运行状态和授权布局不变。值来自Motion发布的遥测快照，不是本地命令回显。

首页保留信号数值和信号格，在刀档位与草袋满载之间显示“超声开/关/--”。只有E0有效且E9运行状态新鲜时显示开/关，断线、未知或失效显示--。调试页第一行“超声波”高亮，按OK选择相反状态；其它调试项目保持只读及原顺序。

等待实际反馈时调试行显示“待生效”，期间忽略重复OK；3000ms未匹配显示“未确认”并允许重试，CH13仍连续发送最后选择。迟到的匹配实际反馈会清除等待。首页始终显示实际状态。解锁/割刀提示优先，进入提示的调试页OK不得复用为授权；设置不占用确认事务或动作序号。

## 版本与验收

规范消息Byte1及自动握手CRC8版本盐使用0x38，CRC8初值为`0x5a XOR role XOR 0x38`；完整消息CRC32相应更新。上行分片、快速完成回执、E9/profile3及CAN布局不变。

软件验证覆盖实际RF STICKS片段、i-BUS解析、Motion配置、四探头限速、会话/非法/失效帧、状态位与告警隔离、UI按键与像素边界，并配套构建双端正式固件。实际CH13通道到达、RF回传时延、障碍物限速效果及长期稳定性仍须在硬件验证，软件通过不等于已经完成这些实测。
