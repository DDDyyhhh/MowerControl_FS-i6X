# FS-i6X 超声波设置与前向障碍提醒 v39

正式双端协议`EXP3_WIRE_VERSION=0x39`，继承[v38设置契约](ultrasonic-control-v38.md)中的CH13编码，以及[v37控制源/授权契约](ch8-control-source-v37.md)。下文替代v38首页布局与E0预留位解释，决策见[ADR 0008](../adr/0008-front-obstacle-warning.md)。

## 本次正式构建配置

双端共用的 `MOWER_ULTRASONIC_AVOIDANCE_ENABLED` 当前为 `0`。底盘开机及重连后保持超声避障停用，忽略 CH13 开启请求。遥控器在 CH13 固定发送 2000 µs。底盘 E0 的 bit14 和 bit15 均回传 0。首页隐藏避障状态和障碍弹窗，调试页首行只读显示「超声波 停用」。

以下超声波开关、前障提示和行走限速行为适用于双端以 `MOWER_ULTRASONIC_AVOIDANCE_ENABLED=1` 构建时。该配置沿用 v38 的开机默认开启和会话基线。

## 距离与提醒

d2/d3（零基索引 1/2）是前向探头，d1/d4 不触发前障提醒。Sensor 解析完整 `CB 55 04` 帧后，在短临界区发布过滤距离、该帧有效通道和解析时刻。原始 0 字段没有可用距离，跳过滤波及距离更新。非零字段仍沿用 30～250 cm 量程钳位和毛刺滤波。

前向弹窗通过 `SR04_ReadDistances()` 仅读取最新完整帧中可用的前向距离，样本年龄须小于 1000 ms。模块持续发帧时，行走控制参考各通道最后接受的非零距离。尚无有效测量的通道按 250 cm 处理。单路零值不清除已经确认的近障。

超声波实际开启且任一前向有效过滤距离 **<40cm** 时提醒；40cm及以上不提醒，关闭开关或样本失效后清除。阈值严格小于40，39cm触发、40cm不触发。Sensor串口采集继续运行；提醒状态本身不授予动力权限，遥控倒车脱困按下节执行，割刀、安全锁和API控制规则不变。

## 下行状态

SENS地址8、类型E0、16bit状态字增加bit15，报文长度及其它位不变。

| 状态位 | 1的含义 |
| --- | --- |
| bit14 / 0x4000 | 底盘实际开启超声波避障 |
| bit15 / 0x8000 | 新鲜前向距离小于40cm，且超声波开启 |

两位均不参与E0故障告警掩码。E9运行/授权布局不变，E9自己的bit15仍表示急停，与E0 bit15分属不同传感器，不能混用。CAN布局和动力许可不变。

## 首页和弹窗

作业仪表首页顶部显示连接状态、控制模式、“避障开/关/--”和信号格。断线、E0无效或E9运行状态失效时，避障显示--。中间并列显示遥控行走设定（API模式显示实速）、割刀档位和「刀设定」机械转速（rpm）。割刀档位来自新鲜 E9。低、中、高档的 FTESC 指令为 12000、15000、16000 eRPM，除以 4 极对，显示 3000、3750、4000 rpm。关闭显示 0，档位未知时显示 `--`。调试页「割刀转速」仍读取实际反馈。下一行显示高度反馈，以及草袋指令、连接与满载状态。底部显示底盘电量和遥控器电压。调试页首行按OK切换超声波。

仅在首页、超声波与障碍状态位同时置位且遥测有效时显示小框，两行文字为“前方障碍”“请倒车”。弹窗保留顶部状态和底部电源。条件解除即自动消失，无须按键确认；调试/维护页不被遮挡，可以继续关闭开关。提醒不消费确认事务或动作序号；解锁和启动割刀确认框优先，已有非模态事务消息仍显示在底部，并在消息出现期间占用电源行。

## 遥控行走与断测恢复

正式 FlySky 遥控在避障开启时按底盘采纳的距离控制行走。距离超过 50 cm 后沿用 100 / 150 cm 的阶梯限速及速度斜坡。

| 条件 | 摇杆响应 |
| --- | --- |
| 前向 d2/d3 任一路 ≤50 cm | 前推和原地转向为零，后拉可低速直线倒车。39 cm 有弹窗，40～50 cm 依然限制前进。 |
| 前向超过 50 cm，侧向 d1/d4 任一路 ≤50 cm | 前推或后拉可低速直线移车，暂限制转向。 |
| 模块未接或完整帧停止满 1000 ms | 回到普通手动控制。若断测前已实施近障限制，两根摇杆都进入中位死区后才清除旧距离。回中前继续按原近距离限制。 |

低速移车按摇杆幅度和速度旋钮计算，倒车沿用 0.8 系数，直线速度指令上限为 0.2 m/s，旋钮为零时保持静止。新有效近距会重新实施限制。关闭避障时跳过这些限速。

低速分支在最终遥控行走适配器执行，直接按杆量计算，避免早先速度斜坡已归零。所有速度仍通过 SafetyOwnershipGate 和原 OID 轮电机换算。物理急停、碰撞、软件锁、失联、未经授权、控制源不匹配和电池停机继续强制零输出。API 控制不使用本遥控分支。

## 版本与验证

规范消息版本字节、自动握手CRC8版本盐与消息CRC32升级为0x39；v35/v36/v37/v38不能与v39建立配套授权会话，两端须一起升级。新测试覆盖实际UART解析→完整样本→Motion判断→SENS E0、39/40/41cm、前/侧探头、关闭/过期/无样本、毛刺滤波、并发快照、时钟回绕、弹窗优先级、实际遥控/最终OID指令的限速、侧向直线移车、断测回中恢复、直线倒车、旋钮为0、所有安全门及API隔离，以及全部UI像素边界。实际传感器安装方向、刷新周期、RF时延和障碍物效果须另行实测。
