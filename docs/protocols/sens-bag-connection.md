# FS-i6X 草袋连接反馈

底盘与遥控器共享的只读契约；定义见 `experiments/ticket03/bag_connection.h`。

## SENS 接口

- 仅 `MOWER_GRASS_BAG_CH6_ENABLED=1` 的生产草袋配置响应地址 11。地址 1～10 的发现、类型、值和用途保持原样。
- 发现请求 `04 8B 70 FF` 原样应答；类型应答 `06 9B E3 02 79 FE`：私有类型 0xE3、值宽两字节。
- 测量请求 `04 AB 50 FF`；应答为 `06 AB low high checksum-low checksum-high`。
- 校验和为 `0xFFFF - sum(除校验和外的各字节)`，16 位小端，与现有 SENS 一致。

| 位 | 含义 |
|---|---|
| bit0 | 已连接：1；未连接：0。取自 PD10，低电平表示已连接。 |
| bit1 | GPIO 采样有效：1。未初始化或无法读取原子快照时为 0。 |
| bit2～15 | `floor(now_ms / 100) & 0x3FFF`，由运动任务采样并随遥测快照发布。 |

连接采样不依赖控制模式、遥控解锁或草袋动作许可；SENS 请求不生成或刷新心跳。没有快照时测量应答为 0，含义是未知，不能解释为未连接。底盘不因该回传改变电机输出。

## 遥控器接收与显示

在已通过 RF CRC 和绑定 ID 检查的 AA 固定槽、AC 可变长度槽中，只接受类型 0xE3、实例/地址 11、宽度两字节；AC 长度不符和截断包不更新状态。缓存不依赖用户是否手动发现/命名模型传感器。

首次有效采样只建立基线；14 位心跳向前推进（模差为 1～8191）后才确认反馈有效，后续仅向前推进刷新时戳。相同心跳可立即反映断开；相同心跳的迟到“已连接”不能覆盖断开。倒序包忽略，采样无效立即清除有效性。

距最后一次推进满 1000ms 即未知；重复包不能续期。超时后恢复须重新建立基线并看到推进。重新绑定清除缓存，失去 RF 遥测时界面也显示未知。32 位时间回绕使用无符号差值；底盘重启或时间计数器跳变后，最多经历一次超时与重新建基线。

| 数据条件 | 首页 |
|---|---|
| 有效且未连接 | 草袋未连接，与 CH6 无关 |
| 有效且已连接，CH6 目标打开/关闭 | 草袋开 / 草袋关 |
| 有效且已连接，CH6 中间值或无效 | 草袋-- |
| 无有效反馈、旧底盘不支持、失联或冻结 | 草袋未知 |

“开/关”是本地发送的 CH6 目标，不表示底盘接受、执行完成或物理到位。草袋重接不触发新动作，仍由既有控制逻辑建立基线并等待新拨动。

旧遥控器不消费地址 11，仍显示其原有指令页面；新遥控器配旧底盘显示草袋未知。部署此功能需更新两端，实机仍须确认接收机能发现并持续轮询第 11 个 SENS 地址。
