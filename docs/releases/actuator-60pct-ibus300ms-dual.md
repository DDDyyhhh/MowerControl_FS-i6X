# 两路推杆60%：300ms主程序及FS-i6X双端固件

2026-11-04按用户要求，将刀盘升降和草袋开合的占空比从50%改为60%。两路正反转及升降归位均使用60%，停止仍为0%。48V母线下理想平均输出约28.8V，瞬时PWM幅度仍接近母线电压。

主程序继续使用300ms有效i-BUS帧超时、原协议及授权流程。急停、碰撞、CH5停车及上位机CAN超时实现未改。升降归位10秒、草袋动作20秒、高度时间表、上升补偿0.8和关门检测屏蔽14秒保留，需在60%占空比下实测速度及行程时间后标定。500ns死区及限流不属于本轮改动。

双端指STM32F407底盘和现有FS-i6X遥控器；遥控器业务源码不改，使用原配套生产配置构建。完整构建入口：

```bash
ASAN_OPTIONS=detect_leaks=0 ./tools/build_blade_ok.sh
```

底盘生产预设为`mower-ok-release`，遥控器生产选项为`PCBI6X_MOWER_BLADE_OK=ON`，沿用草袋集满及协议0x36配套功能。交付目录为`releases/20261104-actuator-60pct-ibus300ms-dual/`，包含两端BIN、HEX及配套ELF/MAP、50%/300ms回退镜像、校验清单和刷写说明。

保留原50%/300ms发布包。本轮仅生成和验证软件，不直接刷写设备，也不重新验证接地整改、电气电压或机械标定。
