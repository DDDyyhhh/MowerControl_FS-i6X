# CH4 / OK / CH7 发布候选版

日期：2026-10-08。状态：历史候选版记录。后续摇杆/CH10、取消恢复和开机首页均已通过用户实机复测，并获批准定版；当前发布代码与固定包见 [正式发布记录](mower-release-20261008.md)。以下RC1/RC2内容保留作历史证据。

## 操作与主页语义

1. 两端建立会话后，遥控器主页顶部显示 READY。底盘仍需通过现有遥控解锁和安全门。
2. CH4 先回中约1500，再左打约988，在新鲜控制器快照有效时出现 START BLADE?。UNKNOWN不弹窗也不接受OK；恢复反馈后需回中再左打。仅割草机主页/数据/故障页上的一次显式 OK 可以发 Confirm；系统菜单里的 OK 不会授权割刀。
3. WAIT RESULT 最多显示2秒，回执早到则提前退出；未收到时返回主页并继续后台等待运动任务最终确认，不将超时显示当作成功。安全门、当前 Pending 请求或物理边沿不匹配时显示 START DENIED。CH6 不能产生或补充确认。
4. 接受后自动回到主页。英文版屏幕显示 BLADE OUTPUT ENABLED，含义为“割刀控制输出已使能”；CH7 GEAR 为控制器实际采用的 LOW/MID/HIGH。没有实际转速反馈，不宣称刀盘已转动。
5. CH7约2000/1500/1000分别为低/中/高档，对应当前 PWM 配置45/50/55%。CH10继续只用于行走设定。
6. CH4回中即撤销输出；WAIT CANCEL最多显示2秒，后台继续等待/发送取消，弹窗退出不代表取消事务已完成。急停、失联、安全门拦截、控制权切换仍通过原有状态机切断输出。主页收到停止快照显示 OFF；没有新鲜快照显示 UNKNOWN，档位为 --。

## 编译和协议边界

- 底盘：CMake preset `mower-ok-release`，`MOWER_BLADE_OK=ON`。
- 遥控器：`PCBI6X_MOWER_BLADE_OK=ON`、真实 mower UI、禁用 mock、禁用台架镜像选项及测试模型自动创建。
- 构建：仓库根目录运行 `./tools/build_blade_ok.sh`。它运行 `./tools/verify.sh all`，再构建匹配候选版；不刷写硬件。
- 正常 debug/release 和 ticket03 台架配置继续独立。候选版共享 ticket03 已验证的固定缓冲编解码、分片、匹配和 CH4 适配实现，没有拷贝出第二套安全门。
- 候选版完整消息版本为0x32，台架为0x31；不可混刷。短结果保留完整双端身份和原消息CRC32；超过短格式容量时仍无损回退完整格式，可能增加等待时间。
- Confirm 的 Accepted 仅在运动任务注入匹配确认、现有 BladeManualControl 本轮确实进入 RUNNING 后发出。重复回执只说明历史操作结果，不再次产生授权；主页始终独立读取当前输出快照。
- 当前启动身份交换沿用台架实现，CRC不是认证，启动身份不是持久化单调重启计数。本轮不声称已完成整个原协议Spec、产品安全评估或最终发布批准。

## 主页状态承载

SENS addr10、私有raw type0xE2、宽度2字节，保持addr1..8既有类型和数值不变；addr9继续承担命令结果。

16-bit runtime word：bit3为快照有效，bit0为输出使能，bit1..2为控制器采用的档位（0停止、1低、2中、3高），bit4..15为运动任务100ms心跳，模4096。运动任务在实际输出调用之后原子发布；使能必须同时满足手动遥控、非零命令和安全门许可。

遥控器只在已绑定会话中消费经过原RF校验/绑定身份检查后的addr10数据。初始值或重绑定后的首值只作基线，观察到心跳推进才显示；1000ms无推进失效。相同心跳中的停止优先，迟到使能不能覆盖停止；反复传送冻结字不能保鲜。长断流后重建基线。该快照用于主页显示及遥控器启动弹窗/OK入口的可用性判断；底盘最终授权仍由原安全门和确认状态机判定。

停止回显延迟由实际SENS/RF轮询决定；状态失效上限为最后一次心跳推进后的约1秒加GUI刷新。新增addr10在实际接收机上的发现、刷新周期和停止回显仍需实测，不能用主机模拟替代。

在原隔离台架先双端刷入匹配候选镜像，检查：

- READY → CH4回中/左打 → 一次OK → WAIT RESULT →主页BLADE OUTPUT ENABLED。
- CH7三档的主页显示与接口实际PWM一致；CH10和CH6不改变割刀授权或档位。
- CH4回中、急停/安全拦截、断链后PWM归零；主页OFF或UNKNOWN，不保留ENABLED。
- 等取消结束后再次启动成功；保持左打、重复OK、旧结果不能再次授权。
- 单端及双端重启、系统菜单内CH4回中/左打后返回主页，需重新确认，不能自动启动。

完成以上实测前，这一包属于发布候选版。
