# CH8 选择控制源，底盘与割刀分别进行 OK 确认

CH8 原来同时承载底盘双拨解锁，不能直接兼作遥控/API 选择。决定在 FlySky 生产配置中将 CH8 专用于控制源，把底盘解锁迁移为 CH11/CH12 确认协议中的独立 CHAS 事务，割刀继续使用 BLAD 事务，避免一次 OK 授予两种权限。

正常控制源切换保留已解锁状态，以减少重复操作，但必须停止并清除上一控制源的动作；故障、失联、CH5 停机及摇杆中断撤销许可。CAN 接收不直接改变执行状态，运动任务统一仲裁；会话和请求代次阻止旧确认在恢复后生效。新协议采用 0x33，新增只读 SENS 代次与状态反馈，要求两端配套升级。接口细节见 [共享协议](../protocols/ch8-mode-and-chassis-ok.md)。
