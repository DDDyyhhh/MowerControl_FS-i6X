# CH8 选择整车控制源，安全授权独立

原正式流程允许 CAN 接收任务改写模式和执行器意图，缺少与遥控器物理选择一致的交接边界。决定以 CH8 作为整车控制源选择：1000/1500 遥控，2000 允许 API；Motion 独占模式和交接状态，CANRx 只发布带实际接收时间、序号及累计停止/待机事件的快照。Comm 同样累计 CH8 档位变化，避免最新快照覆盖中间切换。这样同一周期的切换、故障和新命令有明确的裁决顺序。

选择控制源不授予动力权限。普通切换和摇杆接管保留已有效的底盘授权，但强制行走、割刀、高度和草袋停止，清除巡航、确认及待执行请求；遥控恢复要求摇杆回中 200ms，API 恢复要求切换后新鲜 1 → 2 握手和后续运行帧。摇杆接管另外锁住 API，直到 CH8 回遥控再拨 API。首次解锁和真实故障仍须遥控 CH4 回中 → 左拨 → OK，割刀遥控启动确认独立；CAN Byte7 不再解锁正式配置。API 运行时控制全部四类执行器，仍受同一个 SafetyOwnershipGate、遥控链路和物理安全条件约束。

双端升级 0x37，以版本参与握手和规范消息校验，避免旧遥控器错误理解控制源和授权条件。SENS 0x16 扩展模式 0..4；CAN 0x005/0x507 的字节布局不变，但模式命令以 CH8 选择为前提。此决定替代 ADR 0004 中“EXP3_WIRE_VERSION 固定为 0x36”这一条，继续保留其仅支持正式配置的限制；ADR 0005 的停刀制动/释放策略不变。当前接口、窗口和验收见 [v37 契约](../protocols/ch8-control-source-v37.md)。
