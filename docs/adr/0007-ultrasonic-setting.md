# 超声波避障使用独立 CH13 设置与实际状态回传

FS-i6X 原来没有改变底盘超声波避障配置的入口。选择在正式 STICKS 帧的空闲 CH13 连续传送设置，而不复用割刀/解锁的 CH11、CH12 确认事务；Motion 依据新鲜命令快照独占应用，避免增加第二个配置写者或让设置占用授权事务。首页显示底盘实际配置，调试页负责切换；传感器持续采集，沿用既有遥控行走限速，API 行走策略不扩展。

双端协议升级0x38，以版本参与握手及消息校验；E0 bit14由预留位改为超声波开启状态，不参与故障告警。此决定替代ADR 0006中“当前正式协议0x37”这一条，保留其CH8控制源、独立安全授权及停止规则。配置不持久化，每次启动或新会话恢复开启，并须先观察开启基线才接纳关闭。接口见[超声波设置契约](../protocols/ultrasonic-control-v38.md)。
