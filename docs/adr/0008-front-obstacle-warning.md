# 前向障碍提醒与受控倒车脱困

新增小于40cm的前向障碍提醒：沿用已有前向探头d2/d3与距离滤波，Sensor以短临界区发布完整距离帧及解析时刻，Motion只对1000ms内的新鲜样本计算提醒，防止传感器停更后持续显示旧障碍。选择在既有E0状态字bit15回传布尔提醒，而不增加传感器地址或发送四路距离；提醒和bit14超声波开关一样不属于故障，不授予或撤销动力权限。首页移除“信100”，将超声状态移到右上角，恢复“刀速度”标签和原档位位置，解锁/割刀确认弹窗优先。

双端升级0x39，替代ADR 0007中当前版本0x38及原首页布局，防止旧端将bit15误当故障。保留ADR 0007的CH13设置与开机默认开启，调整其近障停车策略：正式遥控在新鲜前向距离≤50cm时，只允许按摇杆幅度直线倒车，速度指令以现有倒车系数和速度旋钮为基础封顶0.2m/s；前进/原地转向立即停止。此分支避免沿用已经为0或尚未降到上限的速度斜坡，仍调用原最终SafetyOwnershipGate和轮电机换算；API不增加该策略。侧向单独近障或样本失效不放行脱困。接口见[前向障碍提醒契约](../protocols/ultrasonic-control-v39.md)。

后续修复明确了零值处理。四探头帧的原始 0 字段无需钳成 30 cm，也不更新已接受距离。新鲜通道掩码只进入提醒和前向脱困判断。行走限速保留最后有效距离，避免单路断测清除已确认近障。E0/CH13 时序、阈值及 v39 编码沿用。

现场补充空旷处无弹窗仍停、拔掉模块后需重启才能走。后续决定替代前文只在新鲜前障时放行脱困的策略。用和行走斜坡相同的距离判断，前方近障保留前进锁，允许低速直线倒车。仅侧方近障允许受限直线前后移动。完整帧停止满 1000 ms 后，旧近障限制要求两杆回中才能清除，避免保持摇杆时因断测突然改变行走响应。前向提醒继续要求新鲜有效测距。

当前正式版按用户要求恢复停用。双端共用的 `MOWER_ULTRASONIC_AVOIDANCE_ENABLED` 设为 0，底盘停用超声波限速，遥控器首页隐藏超声提示。CH13 和 E0 字段采用 v39。
