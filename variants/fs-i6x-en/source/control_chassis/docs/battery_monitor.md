# 电量显示与低电禁刀

## 当前规则

首页恢复原来的“车xx%”、遥控器电压和电池图标。整车百分比继续采用 BMS 原始 SOC，整车电压保留在调试页，不执行电压转百分比。

| 条件 | 处理 |
| --- | --- |
| 原始 SOC < 20%，或总电压 < 48.00V，连续有效新样本满足2秒 | 锁存低电，停止割刀并禁止再次启动，左上角持续提示“请充电” |
| SOC = 20% 且总电压 = 48.00V | 两项均未低于阈值，不触发低电 |
| 低电后电压回升、普通解锁或切换控制模式 | 仍然禁刀，行走继续使用既有档位和安全规则 |
| 低电后本次上电期间申请启刀 | 弹出“电量过低”“禁止开启割刀”两行提示，2秒后关闭；不发送新的启刀确认 |
| BMS 无反馈、数据达到3秒有效期或数值无效 | 电池数值显示未知，仅在调试页显示“电池反馈异常”；不影响解锁、行走、割刀操作，不产生数据故障停机锁存 |
| 重新上电 | 清除上次低电锁存，重新检查真实数据；不表示已经充电或换电，不自动解锁/启刀 |

低电只限制割刀，不增加行走限速、不设置整车锁定、不撤销行走授权。急停、碰撞、倾斜、链路超时等既有安全限制仍然优先。
未连接和物理安全故障提示优先于充电提示。单独的电池反馈异常不触发首页报错；已经确认的低电即使随后失去反馈，仍提示“请充电”并禁刀。

## 数据与时序

BMS 驱动保持500ms只读轮询。最新样本由 Motion 单写到 `g_app.battery`，保留总压、电流、原始 SOC、FCC/RC、最低/最高单体、编号、最高/最低温度及真实采样时间。
只有新鲜有效的新样本推进2秒确认，相邻样本超过1500ms会重新计时；重复读取或冻结值不能增加低电持续时间。

单位沿用 BMS 驱动：总压0.01V、电流0.1A、容量0.01Ah、单体mV、温度0.1℃；百分比原样透传到 SENS、CAN 0x507 和旧无线反馈。
BMS失效用0xFF表示未知，FS-i6X显示 `--`。序列计数读取有限次返回，避免高优先级 Motion 等待被抢占的 BMS 写任务。
只保留最新样本，不保存采样历史，不执行导出、Flash写入或新增串口日志。

当前临时策略将反馈有效性与动力授权分开：缺失、过期和无效样本仍产生数据失效诊断，但不撤销遥控授权、不设置软件锁定、不使已确认的割刀请求失效，也不要求等待恢复或重新解锁。恢复数据不会自动解锁或启动割刀。
`BatteryMonitor_Rearm` 保留为兼容接口，不再要求数据恢复；低电锁存仍不可由该接口清除。共用执行门下的遥控、API和巡航使用同一电池策略，其他控制权条件保持有效。
低电锁存只在 `BatteryMonitor_Init`（重新上电初始化）清除。首次开机收到有效低电样本时，在2秒确认期间也禁止割刀，避免启动窗口；完全没有有效数据不视为低电。确认前数据失效会终止该次低电计时，已经确认的低电不因数据失效而清除。
已正常运行时的短暂压降不足2秒不会锁存禁刀。

割刀公共 PWM/FTESC 输出入口执行禁刀，Motion 同时清除启动请求、待确认事务和割刀状态。低电到来时，旧请求只允许排空取消事务，不能重新提交 Confirm。
恢复或重启后仍使用既有新控制帧、回中和新确认要求；缓存 OK 不获得权限。低电状态下的普通解锁事务继续可用于行走。

## 遥测接口

继承 `20261026-blade-fast-no-warning-erpm` 的快速启停、移除 THROTTLE/SWITCH 开机警告和 12000/15000/16000 ERPM。SENS 地址1～12的类型、单位和帧长保持不变；13～15专供 E6/E7/E8 四字节快速完成回执，电池诊断不再占用13/14。

最低单体和原因通过地址9/E1的空闲轮询发送。只有原始回执/会话字为0时才填入诊断，完整回执和会话握手永远优先，不中断、推迟或替换任何非零事务字。诊断字不会进入命令/结果解析器，不参与授权或底盘保护。

| E1诊断字 | 数据 |
| --- | --- |
| `(word & 0xE000) == 0x4000` | 低13位为最低单体mV，0表示不可用，超过5000拒绝 |
| `(word & 0xE000) == 0x6000` | bit8～12为5位心跳；低8位为原因：bit0数据失效、bit2总压低、bit5 SOC低 |

发送按最新遥测快照时间的bit8交替两种字，每相256ms；心跳为`(generated_at_ms >> 9) & 31`，在时间回绕时自然循环。接收端要求先收到最低单体、1000ms内再收到原因；第一对建立心跳基线，后续前进1～15的心跳才发布完整诊断。重复/倒退/冻结样本不能延长有效期，3秒无进展显示未知；重新绑定清空基线。事务繁忙时诊断可以暂时未知，低电警告及禁刀状态继续由E0传递，底盘保护独立生效。

E0 bit6继续表示电池反馈异常，仅用于调试；E9及首页通用报错摘要排除此位。bit11表示低电已确认，bit12表示低电禁刀，bit13保留原数据故障停车含义但当前策略不置位；bit14保留，不再发布状态。E1原因bit0继续报告数据失效。
开机读到低电但尚未完成2秒确认时，bit12可先置位表示启动禁止，bit11仍等待确认。
这些状态不会将原始 SOC 改写为0%，也不表示电池化学剩余容量已校准。
调试页保留原始 SOC、整车电压、最低单体与保护原因。

## 验证

- `ASAN_OPTIONS=detect_leaks=0 ./tools/verify.sh host`：状态机、真实 BMS/Motion、三种行走输出、PWM/FTESC 禁刀、遥测、弹窗和既有回归。
- `./tools/verify.sh chassis`：底盘 Debug 构建；另构建 `mower-ok-release`。
- `ASAN_OPTIONS=detect_leaks=0 ./tools/build_mower_user_ui.sh`：FS-i6X构建、像素边界检查。
- 重新生成并校验中文字库，执行 `./tools/svn_preflight.sh`。
- 快速完成回执覆盖两种割刀后端、全部150相位及额外100轮连续启停；E1诊断开启时仍检查原有响应时间上界。

实机需核对电压与 BMS 读数，验证无BMS开机解锁、运行中掉反馈仍能遥控、无效数值仅显示诊断、恢复不自动执行旧操作，并验证低电停刀、重复启刀被拒绝、普通解锁后行走速度正常、低电后掉反馈仍禁刀、回升仍禁刀及重启重新判断。测试不应反复将电池放到 BMS 硬切断。
48V是本次指定的禁刀/充电门限，不是本软件认定的真实0%电量或 BMS 最终断电门限。
