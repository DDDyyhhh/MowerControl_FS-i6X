# 草袋连接反馈使用独立 SENS 传感器

底盘已有 PD10 连接检测，FS-i6X 首页原先只显示 CH6 指令，无法判断草袋是否连接。决定新增 SENS 地址 11、类型 0xE3 的只读连接反馈，保留地址 1～10、故障字与刀盘运行状态的现有含义，避免把连接状态混入故障或挤占刀盘心跳。

草袋连接反馈自带运动任务心跳，遥控器确认心跳推进后才采用数据，冻结回放及断流显示未知。草袋“开/关”仍是连接条件下的 CH6 目标，不表示执行许可或物理到位；本改动不改变草袋动作和安全联锁。线格式、兼容行为和超时约定见 [协议说明](../protocols/sens-bag-connection.md)。

## 满载显示扩展

SENS的15个地址已全部分配，满载显示将地址11/E3扩为四字节：低16位保留原连接与心跳，高16位携带满载及有效标志。满载独立验证心跳与新鲜度，旧两字节反馈仍可提供连接但不能提供满载状态。两端固件配套升级和回滚；不占用控制事务、电池诊断或故障字，不改变满载控制状态机。
